Project Overview


This is a simple full-stack Expense Tracker web application built using Python Flask, SQLite database, and HTML/CSS frontend.
It allows users to add, view, and delete income/expense transactions with automatic balance calculation.


Features

➕ Add income and expenses

📋 View all transactions

❌ Delete transactions

💰 Automatic balance calculation

💾 Persistent storage using SQLite

🌐 Simple web interface using HTML templates


Tech Stack
Backend: Python (Flask)
Frontend: HTML, CSS
Database: SQLite (SQL)
